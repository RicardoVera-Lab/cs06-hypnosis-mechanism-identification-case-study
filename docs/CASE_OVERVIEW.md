# Case Overview

## Starting point

The case began with a strong hypothesis: surprise or pattern interruption might create a special period of increased hypnotic responsiveness.

Rather than treating that explanation as established, CIEC LAB converted it into a falsifiable research problem.

## What changed

The investigation progressively separated several possible contributors that are often blended together:

- expectation;
- context-specific influence;
- demand / response criterion;
- attentional reorientation;
- predictive updating;
- physiological activation / recovery.

The original story became a set of rival explanations with explicit evidence requirements.

## End point

The strongest surprise-specific explanation was not sustained as a demonstrated general mechanism.

Two bounded rival families remained scientifically meaningful:
1. expectation / context / demand;
2. attention / predictive updating.

The first proved distinguishable in principle under adequate measurement precision.
The second proved only partially distinguishable and became increasingly uncertain under realistic instability.

The research closed when existing secondary evidence could no longer decisively adjudicate the remaining rivals.
